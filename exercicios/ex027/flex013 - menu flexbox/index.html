Teste de Flexbox

Flexbox (ou CSS Flexible Box Layout) é um modelo de layout do CSS que facilita a organização e o alinhamento de elementos dentro de um container, especialmente quando o tamanho dos elementos é desconhecido ou variável.Ele permite distribuir espaço entre os itens de forma eficiente e alinhar os elementos tanto na horizontal quanto na vertical. É muito usado para criar layouts responsivos e adaptáveis.

Flexbox é uma ferramenta do CSS usada para criar layouts mais flexíveis e eficientes. Com ele, é possível controlar facilmente a disposição dos elementos em um container, organizando-os em linhas ou colunas, de forma que se ajustem automaticamente ao espaço disponível na tela.Esse modelo foi desenvolvido para resolver limitações dos métodos tradicionais de layout, como o uso excessivo de float ou posicionamento manual. Com Flexbox, o desenvolvedor consegue alinhar, distribuir e redimensionar os elementos de forma simples, tornando o design mais responsivo e adaptável a diferentes tamanhos de tela.
